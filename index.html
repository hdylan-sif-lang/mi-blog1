Despliegue de Aplicaciones Web con Vercel

Publicado el 18 de junio de 2026

El despliegue en entornos de producción es un paso crítico en el ciclo de vida del desarrollo de software. Utilizando herramientas modernas como GitHub Desktop y la infraestructura en la nube de Vercel, podemos automatizar la integración y entrega continua (CI/CD).

Para asegurar un despliegue exitoso bajo el dominio institucional mafinf.social, es fundamental configurar correctamente la visibilidad pública del repositorio en GitHub y delegar los servidores de nombres apuntando a los DNS oficiales de Vercel.
